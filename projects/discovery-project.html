ECE 1100: Discovery Project

Monitor Distance Warning Light

Project Overview

I often found that after long sessions of computer use, I would start leaning closer and closer to my monitor, increasing eye strain. So, I designed this device that uses a light to indicate if I am too close or too far away from my monitor. The device uses an RBG-LED as the warning light and an Ultrasonic Distance Sensor to determine my proximity to my monitor.

The RGB-LED is controlled by the PWM digital pins to adjust the brightness of the colors. I chose the color red as a warning that I am too close, and I chose purple to indicate that I am too far away from the monitor. This was my first Arduino project using an RGB-LED.

The Ultrasonic Distance Sensor uses a trigger signal from a digital pin on the Arduino to send out a sound wave. Then, when the pulse returns, the Arduino reads the signal off another digital pin. The time it takes for the pulse to return allows us to calculate the distance based on the speed of sound. I initially wanted to have distances greater less than 2 feet be too close and distances greater than 5 feet be too far, but it turns out these values weren't realistic after I built the design. I settled on less than 1.5 feet being too close and greater than 2.5 feet being too far away.

The design process involved first creating a schematic, then writing the code, and then assembling the device before tuning/troubleshooting it. I went back and revised the schematic pin connections as a layout different than the one initially designed was easier for the physical connections.

Schematic

This is a simple schematic of the design I implemented with my Arduino and breadboard. I used an Arduino UNO R4 when building the project, but the pins used function the same as the Arduino UNO R3 listed on the schematic. The device was powered by a portable phone charger battery connected to the Arduino over USB-C, supplying 5 V.

In the future, I might design and order a PCB of this device based on the schematic. This would probably use a much simpler microcontroller as this project doesn't require the full capabilities of the Arduino. I would also consider using a different LED component as this RGB-LED does not mix the colors very well.

Code

//defining pins
const int TRIG_PIN  = 7;
const int ECHO_PIN  = 8;
const int RED_PIN   = 11;
const int GREEN_PIN = 10;
const int BLUE_PIN  = 9;

//defining distances (in cm) for too close and too far
const float CLOSE_CM = 45.72;
const float FAR_CM   = 76.22;

//distance sensor parameters; avg every n samples for a more accurate result and to prevent flickering
const int SAMPLES = 5;
const unsigned long ECHO_TIMEOUT_US = 30000;

//amount of blue to mix with the red to get that purplish color
const int red_blue = 60;

//declaring pins and setting initial color to off
void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  pinMode(RED_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  pinMode(BLUE_PIN, OUTPUT);

  digitalWrite(TRIG_PIN, LOW);
  setColor(0, 0, 0);
}

//gets the distance and sets the color of the LED based on the distance
void loop() {
  float distanceCm = getDistanceCm();

  if (distanceCm < 0) {
    setColor(255, 0, red_blue);
  } else if (distanceCm < CLOSE_CM) {
    setColor(255, 0, 0);
  } else if (distanceCm <= FAR_CM) {
    setColor(0, 0, 0);
  } else {
    setColor(255, red_blue, 0);
  }
}

//sets color by writing analog signal to the PWM pins
void setColor(int r, int g, int b) {
  analogWrite(RED_PIN, r);
  analogWrite(GREEN_PIN, g);
  analogWrite(BLUE_PIN, b);
}


//calculate distance from sensor
float readDistanceOnce() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);

  unsigned long duration = pulseIn(ECHO_PIN, HIGH, ECHO_TIMEOUT_US);
  if (duration == 0) {
    return -1;
  }

  //get distance based on speed of time*sound/2 (sound travels to me and back to sensor)
  return duration * 0.0343 / 2.0;
}

//averages over SAMPLES number of readings to get more consistent results and prevent light from repeatedly flickering
float getDistanceCm() {
  float sum = 0;
  int count = 0;

  for (int i = 0; i < SAMPLES; i++) {
    float d = readDistanceOnce();
    if (d > 0) {
      sum += d;
      count++;
    }
    delay(60);
  }

  if (count == 0) {
    return -1;
  }

  return sum / count;
}
